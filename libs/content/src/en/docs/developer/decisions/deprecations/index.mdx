# Deprecations

A deprecation record defines what is retiring, why, affected consumers, replacement, compatibility window, telemetry, milestones, owner, and final removal criteria.

Provide a migration guide before enforcing removal. Communicate through channels appropriate to impact and measure remaining use where possible.

Security or emergency removals may shorten timelines, but the rationale and recovery guidance must still be documented.
