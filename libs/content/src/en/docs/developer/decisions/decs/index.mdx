# Engineering Decision Records

A DEC records an important choice that does not primarily define architecture—for example development policy, tool adoption, compatibility, or operational practice.

State the decision scope, evidence, alternatives, tradeoffs, owner, date, and review trigger. Link related research and proposals.

Do not use a DEC for temporary task notes or implementation detail that is obvious from code. Create a superseding record when circumstances change.
