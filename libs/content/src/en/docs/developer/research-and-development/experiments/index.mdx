# Experiments

An experiment defines a hypothesis, variables, environment, procedure, success criteria, observations, and conclusion.

Pin relevant versions and record configuration so another contributor can reproduce the result. Preserve negative and inconclusive outcomes.

Do not generalize beyond the tested environment. Identify confounding factors and follow-up work, and link decisions that rely on the evidence.
