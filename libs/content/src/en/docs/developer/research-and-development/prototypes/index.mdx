# Prototypes

A prototype tests feasibility, interaction, or architecture with deliberately limited scope.

State what it proves and what it does not. Document shortcuts, missing security controls, unsupported scale, temporary data, and disposal expectations.

Prototype code is not production code by default. Promotion requires design review, testing, security, operations, ownership, and removal of experimental assumptions.
