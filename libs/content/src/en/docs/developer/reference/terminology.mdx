# Terminology

- **Application** — A runnable or deployable Nx project.
- **Library** — A reusable project with a public entry point.
- **Boundary** — A point where ownership, trust, runtime, or contract changes.
- **Contract** — A documented interface between consumers and providers.
- **Integration** — An adapter to an external service.
- **Binding** — Runtime-provided configuration or resource access.
- **Idempotent** — Safe to apply repeatedly without additional effect.
- **ADR** — Architecture Decision Record.
- **DEC** — Engineering Decision Record.
- **RFC** — Request for Comments.
- **R&D** — Research and Development evidence and artifacts.

Prefer these meanings in new documentation and define additional domain-specific terms near first use.
