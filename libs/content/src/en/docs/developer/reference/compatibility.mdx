# Compatibility

Compatibility claims require a defined support target and verification.

Record supported browser ranges, runtime versions, package-manager expectations, platform compatibility dates, and public contract versions in their authoritative configuration.

Avoid relying on undeclared Node.js behavior in edge runtimes. Treat dropping a supported target as a breaking change with migration and release communication.
