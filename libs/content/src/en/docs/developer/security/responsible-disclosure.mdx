# Responsible Disclosure

Do not publish exploitable details, access data beyond what is necessary to confirm a concern, or disrupt production.

A useful private report includes the affected component, impact, prerequisites, minimal reproduction, observed result, suggested severity, and safe supporting evidence. Remove credentials and unrelated personal data.

Project maintainers should acknowledge receipt, restrict report access, reproduce safely, assign ownership, coordinate remediation and communication, and preserve a decision record.

If no dedicated security channel is published, use the repository owner's private contact method rather than a public issue.
