# Security

Security is a design and review requirement across every project.

## Baseline

- Validate untrusted data.
- Authenticate identity and authorize each action.
- Deny by default.
- Minimize permissions and retained data.
- Keep secrets out of code, logs, URLs, and client bundles.
- Use safe failure messages and protected diagnostic detail.
- Design destructive operations with explicit targets and recovery.

Review [Security Model](/documentation/developer/security/security-model), [Authentication & Authorization](/documentation/developer/security/authentication-and-authorization), and [Permission Boundaries](/documentation/developer/security/permission-boundaries).
