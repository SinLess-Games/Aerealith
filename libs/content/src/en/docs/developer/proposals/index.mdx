# Proposals

Proposals describe possible future work. They must not be presented as current product behavior.

Use a proposal when a change affects multiple owners, public contracts, architecture, security, operations, or meaningful migration cost. State status prominently and link the eventual decision and implementation.

Small local changes can proceed through normal issue and pull-request review. Larger changes should use an [RFC](/documentation/developer/proposals/rfcs).
