# Security Testing

Security tests target denied and adversarial paths, not only successful use.

Cover missing and invalid credentials, privilege escalation, cross-tenant access, object ownership, malformed payloads, replay, injection, unsafe redirects, secret exposure, and rate-limit behavior.

Verify logs and errors do not reveal credentials or sensitive records. Test destructive operations for exact targeting and authorization.

Security tools supplement review; passing a scanner does not prove a secure design.
