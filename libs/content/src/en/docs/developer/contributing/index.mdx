# Contributing

Contributions should have a clear problem, bounded scope, evidence of verification, and respect for existing ownership.

Before editing, inspect repository guidance, the owning Nx project, related tests, and current uncommitted work. Reuse established patterns and shared libraries.

Keep changes focused. Update tests and documentation with behavior. Explain risks, migrations, and incomplete follow-up work.

See [Development Workflow](/documentation/developer/contributing/development-workflow), [Pull Requests](/documentation/developer/contributing/pull-requests), and [Documentation](/documentation/developer/contributing/documentation).
