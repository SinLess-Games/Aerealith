# Documentation Contributions

Place user and developer MDX under the matching audience directory. Every page needs valid frontmatter, one clear `h1`, descriptive sections, and current internal links.

Use `index.mdx` for a folder landing page. The filesystem path creates sidebar nesting; `order` controls siblings.

Write task-oriented user guidance and implementation-oriented developer guidance. Mark proposals, drafts, and historical research clearly. Do not invent available features or contracts.

Build content and run frontend validation through Nx before submitting.
