# Coding Standards

Read applicable `AGENTS.md` and project instructions before editing. Keep applications as composition layers, keep reusable behavior in the appropriate library, validate untrusted data at boundaries, and preserve dependency direction.

The authoritative standards are [Code Style](https://github.com/SinLess-Games/Aerealith/blob/main/docs/engineering/Code%20Style.md), [TypeScript Standards](https://github.com/SinLess-Games/Aerealith/blob/main/docs/engineering/TypeScript%20Standards.md), [Dependency Rules](https://github.com/SinLess-Games/Aerealith/blob/main/docs/engineering/Dependency%20Rules.md), and [Monorepo Rules](https://github.com/SinLess-Games/Aerealith/blob/main/docs/engineering/Monorepo%20Rules.md). They may describe target requirements; source and accepted decisions establish what is currently implemented.

For new architecture, record the decision or RFC required by repository conventions rather than encoding a new platform boundary only in code.
