# Releases

A release is a traceable set of validated changes delivered to an environment or consumer.

Release material should identify version, scope, compatibility, migrations, configuration, security impact, rollout, rollback, owner, and verification.

Use the [Release Process](/documentation/developer/releases/release-process), maintain the [Changelog](/documentation/developer/releases/changelog), and publish [Migration Guides](/documentation/developer/releases/migration-guides) for consumer action.
