# Migration Guides

A migration guide defines affected versions and consumers, prerequisites, before-and-after behavior, ordered steps, verification, rollback, and support window.

Include code or configuration examples that match the released contract. Identify irreversible steps and required backups clearly.

Test the guide from a supported starting state. Keep it available for the duration of the supported migration window.
