# Changelog

Changelog entries should be concise, factual, and organized by release.

Use categories such as Added, Changed, Fixed, Deprecated, Removed, Security, and Migration. Describe impact rather than commit mechanics, and link detailed guidance where needed.

Do not include secrets, private incident details, or unverified claims. Historical entries should remain stable; correct material errors transparently.
