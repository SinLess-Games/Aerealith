# Release Process

1. Define scope and version.
2. Confirm required changes are reviewed and merged.
3. Run required Nx validation.
4. review dependencies, migrations, configuration, and security notes.
5. Create release notes and migration guidance.
6. Deploy through the approved workflow.
7. Verify health and representative journeys.
8. Record outcome and follow-up.

Stop or roll back when verification fails. Do not silently add unrelated changes to an active release candidate.
