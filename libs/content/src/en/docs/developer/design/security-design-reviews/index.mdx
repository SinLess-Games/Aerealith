# Security Design Reviews

Review security before implementation for new external interfaces, sensitive data, authentication, privileges, integrations, destructive actions, and production infrastructure.

Identify assets, actors, trust boundaries, abuse cases, authorization decisions, secret handling, privacy impact, logging, rate limits, dependency risks, and incident signals.

Record required controls and residual risk with owners. Re-review when scope or permissions expand materially.

Security review supplements normal code review and testing; it does not replace either.
