# Technical Designs

A technical design connects a defined problem to an implementable and verifiable solution.

Include architecture and dependency changes, public contracts, data flow, trust boundaries, runtime constraints, failure modes, observability, compatibility, rollout, rollback, and testing.

Separate confirmed repository facts from proposed behavior. Use diagrams where relationships or sequences are difficult to explain linearly.

Resolve high-impact open questions before implementation; track lower-risk follow-up explicitly.
