# Honorable Mentions

Aerealith appreciates every person who reports an issue, improves documentation, reviews a change, tests an early workflow, or shares thoughtful feedback.

## Community support

Many valuable contributions happen outside the repository. They include:

- answering questions and welcoming new participants
- reproducing issues across browsers or devices
- identifying confusing language and usability barriers
- reviewing accessibility and keyboard behavior
- suggesting safer defaults and clearer permission boundaries
- sharing experience from real workflows

These contributions help turn isolated feedback into a more dependable product.

## Research and review

Technical research benefits from people who question assumptions, compare alternatives, locate stronger evidence, and document why an approach should be adopted or rejected.

The [Research & Development](/documentation/user/research-and-development) section preserves this reasoning so future contributors can understand how decisions were reached instead of repeating the same investigation.

## Open-source maintainers

Aerealith builds on open standards and open-source projects maintained by individuals and organizations around the world. Their releases, documentation, security work, issue triage, and long-term stewardship provide the foundation on which this project operates.

See the [Developer Architecture](/documentation/developer/architecture) for the principal technologies used by the repository.

## A living record

This page is intentionally a living record. Recognition may be expanded as the project grows and contributions are verified.

To request an addition or correction, provide:

1. the contributor or project name
2. a concise description of the contribution
3. a public reference when one is available
4. confirmation that public attribution is appropriate

Return to the main [Credits](/documentation/user/credits) page for named acknowledgements.
