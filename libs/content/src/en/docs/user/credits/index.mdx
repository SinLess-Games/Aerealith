# Credits

Aerealith is shaped by the people who build it, test it, document it, challenge its assumptions, and support its continued development.

This page records named contributions with permission and recognizes the broader communities whose work makes the project possible. See [Honorable Mentions](/documentation/user/credits/honorable-mentions) for additional acknowledgements.

## Founding engineering

- **Timothy Pierce** — Founding engineering and continued development of Aerealith.

## Community contributions

Community contributions include:

- reporting reproducible defects
- proposing and reviewing improvements
- testing workflows and accessibility
- correcting or expanding documentation
- sharing operational and security feedback
- helping new community members

Every useful report, review, and correction improves the project, even when it does not result in a code contribution.

## Open-source acknowledgements

Aerealith depends on open-source software and the people who maintain it. The project is especially grateful to the communities building the web platform, TypeScript, React, Vite, React Router, Nx, Cloudflare tooling, testing libraries, accessibility tools, and the many transitive dependencies used throughout the repository.

The [Developer Architecture](/documentation/developer/architecture) describes the principal technologies used by the project. Package manifests and lockfiles remain the authoritative record of specific dependencies and versions.

## Recognition and corrections

Credits should be accurate, respectful, and published with appropriate consent. If a contribution is missing, incorrectly described, or attributed to the wrong person, report the page and the requested correction so the project can review it.
