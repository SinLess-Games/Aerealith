# Accessibility

Use your browser's zoom, text-size, contrast, keyboard, and screen-reader features when navigating Aerealith. The current frontend uses labeled form controls and semantic navigation in its core account and documentation paths, but accessibility is an ongoing quality requirement rather than a claim that every future feature is barrier-free.

If you encounter a barrier, report the page address, browser and assistive technology, expected behavior, actual behavior, and the smallest reproducible steps. Do not include credentials or private content in the report.
