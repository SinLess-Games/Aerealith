# Integrations

Integrations allow an enabled Aerealith workspace to read from or act on an external service. Availability varies by deployment and account.

## Before connecting

- Confirm you are signed into the intended external account.
- Review the requested permissions.
- Grant only the access needed for the workflow.
- Understand whether actions are reversible.
- Keep credentials and recovery codes out of ordinary prompts.

## During a workflow

Resolve exact targets before approving an action. Check recipients, channels, repositories, calendars, environments, and attached content immediately before submission.

If an action times out, inspect the external service before retrying. A completed action with a delayed response can otherwise be duplicated.

## Disconnecting

Remove a connection when it is no longer needed, when ownership changes, or when access may have been compromised. Disconnecting Aerealith does not necessarily undo actions already completed in the external service.

Available service-specific guidance appears as nested pages, including [Discord](/documentation/user/integrations/discord).
