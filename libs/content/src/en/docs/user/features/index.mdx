# Features

Aerealith combines guided AI workflows, documentation, research support, and optional connected services. Exact capabilities depend on the deployment, account permissions, and integrations enabled for your workspace.

## Core capability areas

- **Conversation and drafting** — Develop, rewrite, summarize, and structure content.
- **Research support** — Organize questions, evidence, findings, risks, and decisions.
- **Planning** — Convert goals and requirements into milestones, tasks, and review criteria.
- **Technical assistance** — Explain code, propose changes, and support verification workflows.
- **Documentation** — Create and maintain task-oriented user and developer material.
- **Connected actions** — Work with approved external services when an integration is available.

## Availability and permissions

A visible feature may still require account access, workspace configuration, or authorization from an external service. Review permission prompts and confirm the target account before connecting a service.

<Requirement title='Verify important output'>
  Feature output can be incomplete or incorrect. Verify facts, code, targets,
  and external actions before relying on or approving them.
</Requirement>
