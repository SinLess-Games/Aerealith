# Guides

Guides describe reusable ways to work with Aerealith. Adapt each pattern to the sensitivity, impact, and complexity of your task.

## Plan a task

1. Describe the outcome and intended audience.
2. Provide only the relevant context.
3. State constraints and prohibited assumptions.
4. Define the output format.
5. Add acceptance criteria.
6. Review the result before approval.

See [Writing Effective Requests](/documentation/user/getting-started/writing-effective-requests) for a reusable request template.

## Research a question

Separate the research question, evidence, interpretation, recommendation, and unresolved uncertainty. Prefer primary sources and record when each source was checked. For longer investigations, preserve status, confidence, owners, and decision dates.

The [Research & Development](/documentation/user/research-and-development) collection shows how Aerealith records technical investigations.

## Prepare content for others

Identify what the audience knows, what they need to decide or do, and which facts require verification. Remove internal notes and sensitive information before publishing.

## Review high-impact work

Use a second reviewer for security, production operations, legal obligations, financial decisions, personal data, or irreversible changes. Follow [Reviewing Results](/documentation/user/getting-started/reviewing-results) and stop when the target or consequences are unclear.
