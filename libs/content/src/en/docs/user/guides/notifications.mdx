# Notifications

The authenticated header displays a notification icon and indicator. It is currently a visual control only: the repository does not implement a notification inbox, preferences page, delivery provider, or user notification workflow.

Treat notification delivery, push permissions, email alerts, and notification settings as planned unless a specific deployed service documents them. Security alerts should be verified through the official deployment address rather than links in unexpected messages.
