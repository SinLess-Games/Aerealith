# Workflows

General-purpose workflow creation, automation, triggers, and approvals are planned product direction. The current repository does not provide a user-facing workflow builder or demonstrated execution service.

If an enabled deployment later provides a workflow feature, begin with a reversible, low-impact task. Define the target, permissions, expected output, and approval point. Check the destination before retrying a timed-out action, because an external action may have completed.

Read [Integrations](/documentation/user/integrations) before allowing a workflow to access another service.
