# Modules

Aerealith's architecture describes modules as future platform capability boundaries. The current repository does not expose a user-facing module catalog, installation flow, or module permissions screen.

Do not interpret marketing or roadmap references to modules as an available feature. When modules become available, review the publisher, requested data access, and permission scope before enabling one.
