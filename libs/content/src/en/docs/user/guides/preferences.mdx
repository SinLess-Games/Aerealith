# Preferences

The authenticated shell includes a theme toggle. The account edit interface also exposes timezone and locale values. Their persistence depends on the configured account service.

Notification, assistant, memory, and workspace preference controls are not implemented as current user-facing features in this repository. Do not assume a visible theme selection changes other settings or applies across devices.

Use the smallest amount of personal information needed for a preference. For data handling and browser controls, see [Privacy](/documentation/user/safety-and-privacy/privacy).
