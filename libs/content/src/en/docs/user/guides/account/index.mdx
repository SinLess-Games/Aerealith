# Account Access

The frontend and auth service provide account access in configured deployments. Start with [Create an Account](/documentation/user/guides/account/create-an-account), [Signing In](/documentation/user/guides/account/signing-in), [Email Verification](/documentation/user/guides/account/email-verification), and [Account Recovery](/documentation/user/guides/account/account-recovery).

For information visible after sign-in, see [Profile & Account](/documentation/user/guides/profile-and-account) and [Security & Sessions](/documentation/user/guides/security-and-sessions).
